Help Center

Plain answers for the two things every shop has to do first: install the agent and connect devices.

This is a starter help page. Replace the steps below with your real agent download link, supported Windows versions and device list before you send customers here.

Getting started

  1. Register your shop with your shop name, address and contact details.
  2. Sign in on the computer that your printers and scanner are connected to.
  3. Install the local agent on that computer. It is a normal Windows program, installed once.
  4. Keep the agent running while you work. If it is closed, jobs cannot reach your printers.
  5. Open the dashboard from any other computer in the shop using a browser.

Local agent guide

What it does. The agent sits between the website and your equipment. The dashboard sends a job to the agent, and the agent hands it to the printer or scanner attached to that computer. Nothing prints unless the agent is running.

Which computer. Install it on the machine the devices are physically connected to, or the machine that can already reach them on your shop network. A second computer only needs a browser.

If a printer does not appear. Confirm Windows can print a test page to that printer first. Then restart the agent. If it still does not show, send support the printer make and model and the Windows version.

Checking a printer or scanner

Device support depends on your exact model and its drivers. Before you commit to a plan, email support@example.com with:

  • Printer or scanner brand and model number.
  • How it connects — USB cable or shop network.
  • The Windows version on the computer it is attached to.
  • Whether Windows prints or scans with it successfully today.

When the internet is down

New jobs cannot reach the agent while your connection is out. Print urgent work directly from the computer as you normally would, then enter those jobs in the dashboard afterwards so your records stay complete.

Contact support

Email support@example.com. Include your shop name, the device involved, what you expected to happen and what happened instead. Response times depend on your plan.
